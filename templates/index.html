ARCHITECTURAL PIPELINE

Zero-Trust Inspection Process

Every incoming URL undergoes a rigorous 4-stage pipeline before a security verdict is rendered.

STAGE 01

Sanitization & SSRF Guard

Validates URL schema, parses IPv4/IPv6 fragments, blocks loopback/private CIDR ranges, and normalizes punycode characters.

Defensive Firewall
STAGE 02

15-Vector Feature Engine

Extracts entropy, hyphen count, lookalike subdomains, suspicious TLDs, keyword spoofing, redirection depth, and WHOIS domain ages.

Vector Extraction
STAGE 03

Ensemble ML Scoring

Trained Scikit-Learn Random Forest ensemble weights the extracted feature matrix to output a calibrated probability distribution [0.0 - 1.0].

Scikit-Learn ML
STAGE 04

Explainable AI Verdict

Transparent reasoning engine returns human-readable security signals explaining why the site was flagged, eliminating black-box opacity.

Explainable AI (XAI)

import requests

response = requests.post(
    "https://phishguard-api-ttou.onrender.com/predict",
    json={"url": "http://suspicious-bank-login.com/auth"},
    timeout=5
)
data = response.json()
print(f"Prediction: {data['prediction']}, Risk: {data['score']:.2%}")
const res = await fetch("https://phishguard-api-ttou.onrender.com/predict", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ url: "http://suspicious-bank-login.com/auth" })
});
const data = await res.json();
console.log("Verdict:", data.prediction === 1 ? "Phishing" : "Safe");
