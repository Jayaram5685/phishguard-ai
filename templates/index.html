INSPECTION PIPELINE

How It Detects Threats

A rigorous 4-stage pipeline processes every URL before rendering a verdict.

STAGE 01
🔗

Sanitization & SSRF Guard

Validates URL schema, checks private/loopback CIDRs, and normalizes punycode spoof attempts.

STAGE 02
🔍

15-Vector Feature Engine

Extracts entropy, hyphen lookalikes, suspicious TLDs, keyword spoofing, and WHOIS domain ages.

STAGE 03
🤖

Ensemble ML Scoring

Trained Random Forest classifier evaluates the feature vector and outputs calibrated probability scores.

STAGE 04
✅

Explainable AI Verdict

Provides human-readable security reasons explaining why the site was flagged — no black box.
