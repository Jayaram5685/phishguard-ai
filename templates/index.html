    How It Works

    01
    🔗

    Submit URL

    Paste any suspicious URL into the scanner. We validate and sanitize the input before processing.

    02
    🔍

    Feature Extraction

    We extract 15 features: URL syntax patterns, DNS/WHOIS records, and page behavior signals.

    03
    🤖

    ML Classification

    A trained Random Forest model scores the URL. We also ship XGBoost, LightGBM, and Logistic Regression.

    04
    ✅

    Explainable Verdict

    Get a verdict with probability score and human-readable reasons — never a black-box answer.

    Features

    🛡️

    SSRF Protection

    Outbound fetching is guarded against server-side request forgery — internal resources are never exposed.

    ⚡

    Rate Limiting

    Sliding-window rate limiting keyed on real client IP prevents abuse while serving legitimate users.

    🔐

    Hardened API

    Security headers, strict CORS, structured errors, and no stack traces exposed — ever.

    📊

    Honest Evaluation

    Domain-disjoint splits, Wilson confidence intervals, and explicit baselines — no inflated metrics.

    🧩

    Chrome Extension

    One-click scan from the browser toolbar. Premium dark UI with real-time verdict display.

    🔄

    Reproducible

    train_model.py --check refits all 24 experiments and asserts committed metrics reproduce within 1e-6.
